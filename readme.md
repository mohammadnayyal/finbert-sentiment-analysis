# Financial Sentiment Analysis with FinBERT

This project uses the FinBERT model to analyze sentiment in financial text.  
FinBERT is a BERT-based transformer model fine-tuned for financial sentiment classification.

## Example
Input:
> "The stock market is crashing due to inflation fears."

Output:
> Sentiment: Negative (91.3% confidence)

## How to Run
1. Clone the repo
2. Run: `python sentiment_analysis.py`

## Requirements
- transformers
- torch
